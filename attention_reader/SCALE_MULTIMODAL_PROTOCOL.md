# Native transfer and cross-sense relation check

This extends the small 14B scene-template qualification to matched full-context observations of a real multi-genre stream. It then checks the newer native audiovisual Qwen3-Omni-30B-A3B-Thinking backbone. The initial reference remains c8 on Qwen3-8B.

1. Extract layer-24 states from native 8B and proportional layer-27 states from native 14B on identical token IDs and full contexts. Fit a 128-dimensional ridge bridge from 14B activity to the original reader's 256 keys plus 256 values on readings 256–999. Test on readings 1500–2999. Gate at held-out R² >= 0.80, fixed before observing these natural-stream results. Preserve failures; passing the earlier template check does not override this test.
2. Input R² alone is insufficient. On held-out windows also compare the reader at the same four fixed stances: mean attention total variation must be <= 0.15, mean reading-summary cosine >= 0.90, and destination cosine >= 0.90. Both input and functional gates must pass. Run the complete current mechanism on native 8B observations, with own, unused, and neighbor schemas, six starts per arm, four different warm-ups then shared observations, 3000 readings. If the 14B bridge qualifies, repeat the mechanism and controls on 14B. Score only after reading 1500 so evaluation excludes bridge-fitting material. This is recorded native-backbone operation, not a live 14B action-return loop.
3. Repeat the independent bridge qualification for native Qwen3-Omni-30B-A3B-Thinking, read layer 32. No quantization or external progress reward. Run its copy population only if qualified. A failed bridge does not show that the backbone cannot support self-modeling; it shows this particular 8B reader cannot be interpreted as a faithful port through this bridge.
4. Use original audiovisual relational materials: a diagram specifies before/after locations, and speech specifies whether an actor saw the relocation. Correct first-search location requires both. Cross two directions and two witnessing conditions. Keep image size and audio duration fixed. Replace image with a neutral generated image, speech with same-duration silence, and both as controls. Measure the final question's fused representation at the reader layer; save non-additive interaction. Native output is a substrate check, not a result of the added reader acting. No claim of qualia, rich emergence, or a personality follows from the four questions or non-additivity.
5. A qualified port may observe the native fused sequence with the complete reader. Same-start/same-input copies must remain identical; artificial individuality is a failed null check. Cross-history populations are tested separately. Do not introduce an exploration schedule to make them look organized.

Limits: one multi-genre stream, one frozen c8 reader, proportional layers rather than a layer search, and a very small authored relation assay. No argument about model-size emergence can be based on this alone. A genuine fully coupled multimodal life needs a qualified act-return route, cross-history trials, and held-out semantic behavior before release claims can expand.
