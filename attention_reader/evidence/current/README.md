# Compact evidence for the 3 November edition

Wiktor Tomasik · 3 November 2026

`current_runs.npz` contains unchanged numerical fields from 28 recorded dose/ownership lives and 36 prototype-control lives. It includes selected-content profiles, attention separation, stance, decoded direction and compact picture. These are recorded-reader experiments, not live language generation. Metadata names original run IDs and raw-file hashes; original text and native Qwen observations are not included.

Run `python recheck_current.py` with NumPy to recompute persistence and genre responsiveness from the saved profiles and verify the published aggregates. No language model or GPU is needed. Three-dimensional display coordinates are derived separately using one fixed PCA basis across displayed variants.

The source folder preserves relevant implementation/scorer files. Local document names in commentary are normalized; executable statements are unchanged. This is not a self-contained new training distribution: full original experiments also require the existing reader and upstream observations, and their original environment/dependencies. Paths in exported configurations are normalized; use the source run IDs and hashes for provenance. The c8 reader tensors are identical to the active c8 interface; optional interpretation routes are variants, not new default reader weights.

The reference replays match the earlier recorded states exactly in twelve checks. The dose summaries concern four previously identified individual starts; these are not four independently trained neural readers. Picture prototypes were fitted descriptively to recorded lives.
