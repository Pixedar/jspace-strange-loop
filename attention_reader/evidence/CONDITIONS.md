# Condition and quantity legend

Every profile is a selected-content average from one four-copy life. The main scoring compares the correlation of the same copy across separated segments with the correlation to other copies. This measures persistence of a distinctive reading direction; a fixed code or simple cycle could also be persistent, so it is not an emergence or consciousness score.

| Group | Conditions and their meaning |
|---|---|
| `recorded` | `habit`: turned stance and habit without schema feedback. `own`: complete context-schema reference. `neighbor`: its schema learns the cyclic neighbor's attention. |
| `recorded_exchange` | `exchange`: copies 0/1 exchange schemas during readings 1000–1999. `random`: equal-size random schema changes during the same interval. Compare with `recorded/own`. |
| `study` | New matched freeze study. `own`: continue learning. `freeze_schema`, `freeze_habit`, `freeze_both`: stop the indicated updates from reading 1000, retaining their learned content in operation. |
| `fresh` | Twelve new starts, seeds 22–33, with complete `own` and `neighbor` schema conditions. Same previously studied main text. |
| `context_transfer` | `familiar` continues the original stream; `changed` switches to stream 5. `plastic` continues updating; `frozen` stops habit and schema updates. Each is a 1200-reading continuation from an exact developed state. |
| `native8` | Matched native full-context 8B observations: schema `own`, `neighbor`, or learned but unused (`none`). Score after reading 1500. |
| `mean_controller` | The context-schema output is replaced by a recent average learned from `own` or `neighbor` attention, with the same forgetting and strength calibration. |
| `s65`, `s69` | Historical integrated live-model experiments, on different texts. The letter codes below preserve provenance. |
| `s79` | Historical true-counterfactual echo-channel diagnostic. The codes below distinguish attention and values. |

Historical live codes: `N` no action; `A` complete acting reference; `A25` reduced action setting 0.25 instead of 0.5; `An` neighbor's action enters the row; `Ae` direct read-layer echo without the intervening processing; `Asw` schema exchange while acting; `Ash` equal-size random schema change while acting; `SnA` acting with a neighbor-learned schema; `TA` turned stance acting without habit/schema. The original source configuration and report determine the exact per-arm settings; do not combine these as one intervention.

Echo diagnostic: `Kk` action with echo present in keys and values; `Ok` true counterfactual removes the echo from attention keys; `Ov` true counterfactual removes it from values. These are experiment-supplied controls, not learned abilities.

Genre labels: 0 dialogue, 1 expository, 2 news, 3 authored reports, 4 story. A profile segment averages 100 readings. Index fields `first_segment` and `gap_segments` define each scoring window; shorter context-continuation metrics are not the same length as main-life metrics. Dimensions are model activity coordinates, without assigned psychological meanings.
