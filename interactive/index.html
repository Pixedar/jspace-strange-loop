Does the loop respond to its own state?

A small network reads a language model’s internal activity. Its reading sets the next control state, which changes what it reads next. This experiment tests how training it to describe its own possible updates changes that feedback.

What can this comparison tell us?

The bars show measured one-step responses of trained interfaces. At the default moment the self-description run produces widely separated next states, often close to two groups; the control’s next states remain close together. These are numerical control states, without demonstrated word labels or psychological meanings.

This selected pair does not establish a general success rate or isolate every training difference. In the initial small-model comparison, 2 of 5 self-description runs sustained substantial dependence without persistent two-state oscillation. The reader is the main return path

Large movements almost disappear when the state can no longer change the reader’s query. They remain when the separate model-attention route is held fixed. This supports a causal role for feedback through the reader in this trained run.

The reading still changes model predictions

Across five self-description runs, applying the reader’s attention inside the model changes its highest-probability next token at 11–16% of positions on matched texts. Prediction loss changes by −0.14% to +1.51%. A control describing another loop changes predictions too.

Influence on the model and feedback from the model are separate measurements. Interventions restricting the state to the model route produce less than 1% of the full starting-state-dependent variation. Most of the loop’s measured dependence remains in the small reader.

Train a description of how the loop responds

The language model’s weights stay fixed. A small network learns how to read its recent activity and carry a state between readings.

  1. 1 · READ

    Weight recent activity

    The current eight-number state sets a query over the model’s activity at 16 recent text positions.

  2. 2 · SUMMARIZE

    Compress the reading

    The weighted reading becomes a 32-number summary. “Summary” means a learned vector, not a sentence or image.

  3. 3 · RETURN

    Set the next state

    A decoder maps the summary to eight control numbers. Those numbers change the next query, closing the loop.

A description used during training

A second network takes the summary and candidate starting states and predicts their updates. Training asks the summary to distinguish its copy’s response pattern from other copies’ patterns. The four copies share weights while reading different texts. In the control, the target is another run’s recorded responses.

Remove a common-destination shortcut

Different starting states can all lead to one next state. Naming that destination can identify the copy without describing any dependence on the starting state. Subtracting the common destination leaves the differences between possible next states for the summary to distinguish. This is the centered-field objective.

The description and the loop it describes can both change under this training loss. The prediction network is not consulted during operation: the summary decoder still supplies the next state directly.

Let the reading affect the model

The same attention weights can also bias attention inside the language model. This shared channel, called the spotlight, lets prediction loss reach the small reader. The path-cut experiment distinguishes this route from feedback directly through the reader.

Dimensions, code and source recordings

The control vector has eight coordinates and length one. The summary has 32 coordinates and length √32. The main model is Qwen3-0.6B; only the surrounding interface is trained. Methods and reproduction code specify numerical settings and configurations.
