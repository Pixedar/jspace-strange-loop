# Contributing

Contributions and independent checks are welcome. Start an issue or pull request with the question, the exact reference configuration and run provenance. Distinguish inherited findings from the proposed change. Human review is needed for scientific claims; generated explanations and moving plots are not empirical evidence by themselves. Code contributions use the applicable AGPL-3.0-only terms and author-owned research text/data use CC BY-SA 4.0; retain third-party terms and contributor credit. No copyright assignment is requested.
